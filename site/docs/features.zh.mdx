Gui 是一个功能非常丰富的终端。

终端功能可以分成两类：面向用户的功能，以及面向终端程序开发者的功能。

面向用户的功能是多窗口、标签页、分屏、连字等等。这类功能让使用终端更顺手，而且不需要改动正在运行的终端程序（例如你的 shell、文本编辑器等）。

面向终端程序开发者的功能是 Kitty 图形协议、Kitty 键盘协议、颜色上报、超链接等等。这类功能让终端程序能做到别的终端模拟器做不到的事。虽然用户不会直接使用它们，但每天用的程序因此变得更强，用户同样受益。

### 平台原生功能

Gui 的主要设计目标之一，是在 Windows 上看起来、用起来都像一个专门为平台打造的原生应用。下面是 Gui 的一些平台原生功能。

- **快速终端**：从屏幕边缘滑出的下拉终端，一个快捷键就能叫出 shell，不必离开当前窗口。
- **原生窗口、标签页与分屏**：标题栏、标签栏和窗格标题栏都是 WinUI 控件，而不是自绘文本。
- **亚克力透明与背景模糊**：一次性作用于整个窗口，终端与窗体共享同一层表面。
- **自定义着色器**：把 GLSL 编译成 Win2D 可用的 HLSL，可多级叠加，并可只让焦点窗格运行动画。
- **中文输入**：组字串实时绘制在光标处，不会被混进按键编码流程。
- **设置页与命令面板**：主题、字体、行为都能直接改，不必手写配置；命令面板列出每个动作及其当前快捷键。

## 终端（VT）功能

Gui 没有另写一套解析器：由 libghostty-vt 解析 ConPTY 字节流。因此终端行为、控制序列与协议都跟随 Ghostty，而 Ghostty 遵循这些原则：

1. xterm 兼容：xterm 是终端模拟事实上的标准。xterm 怎么做，我们就怎么做。

2. 协议来源兼容：定义某个协议的终端如果表现出特定行为，我们就跟随该行为，即使协议没有写。

3. 事实标准兼容：如果某种行为已被广泛接受为标准，我们就跟随它。“广泛接受”通常取决于主流意见与使用情况。

Gui 支持的终端开发者功能清单，可参考 Ghostty 的 [VT 参考](https://ghostty.org/docs/vt/reference)——Gui 对同样的查询给出同样的回答。
