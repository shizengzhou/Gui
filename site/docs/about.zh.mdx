<DocHead title="关于 Gui" />

<Prose>

Gui 是一个快速、功能丰富的 Windows 终端模拟器：平台原生界面、GPU 加速渲染，解析内核来自 Ghostty。Windows 上的 Ghostty，又不止于此。

为什么做 Gui？
> As a project, we've decided to drop any roadmap for Windows support in the Ghostty GUI.

因为 Ghostty 官方不打算做，所以我做。花我的 token，就不用花你们的 token。鉴于 Ghostty 官方在其他两个平台的技术选型，我觉得官方做的话会选择 WinUI，所以我选择 WinUI。

</Prose>
